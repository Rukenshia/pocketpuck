# Font sources

These headers were generated with Adafruit GFX `fontconvert` at 9 pt for
codepoints `0x20` through `0x7E` from the following Google Fonts files:

- `ofl/ibmplexmono/IBMPlexMono-Medium.ttf`
- `ofl/chakrapetch/ChakraPetch-SemiBold.ttf`
- `ofl/vt323/VT323-Regular.ttf`
- `ofl/sharetechmono/ShareTechMono-Regular.ttf`
- `ofl/audiowide/Audiowide-Regular.ttf`
- `ofl/rajdhani/Rajdhani-SemiBold.ttf`
- `ofl/quantico/Quantico-Bold.ttf`
